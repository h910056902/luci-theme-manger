救砖通道（这台机器真实可用的）

方式怎么进说明
U-Boot TFTP PC 设 192.168.1.88 / 255.255.255.0
上电 2 秒内打断		 U-Boot 里 ipaddr=192.168.1.1、serverip=192.168.1.88， bootdelay=2。需要串口才能可靠打断。
OpenWrt Failsafe 上电后指示灯快闪时按 Reset 设备变为 192.168.1.1，telnet 192.168.1.1 进 （本机已装 failsafe dropbear，也可 SSH）。
分区回写 在 failsafe 或正常系统里 dd if=备份.bin of=/dev/mtdX，按 SHA256SUMS 校验后再回写。

建议把备份目录整体拷到电脑保留一份：/overlay/kp-fw-backup/。 只保留在设备上，一旦 overlay 损坏就一起没了。

命令行工具（默认 dry-run，加 --apply 才真正写入）：

/usr/bin/kp-uboot status          # 当前 env / 关键变量
/usr/bin/kp-uboot caps            # 从 FIP 探测 U-Boot 能力
/usr/bin/kp-uboot delay 5 --apply # 等待窗口 2s → 5s（风险最低）
/usr/bin/kp-uboot menu --apply    # 装启动菜单（preboot=bootmenu，需串口）
/usr/bin/kp-uboot menu-remove --apply
/usr/bin/kp-uboot env-restore /overlay/kp-fw-backup/uboot-env/env-*.txt --apply

为什么没有直接替你写：env 是单份且无冗余，而 bootmenu 只有在串口控制台下才看得见。 在没接串口的情况下改 preboot，一旦渲染异常就只能拆机；所以这里只提供工具与命令，由你决定何时执行。
